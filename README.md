# かなづかいどっち（kanazukai-dotchi）

ことばの発音（カタカナ）と意味を見て、ひらがなの正しい書き方（こんにちは・こんにちわ、ちぢむ・ちじむ、おおきい・おうきい など）を当てる1日5問の学習ゲーム。正解したら「どの決まりで？」（7つ）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/kanazukai-dotchi/>

- 中身は、内閣告示「現代仮名遣い」（昭和61年内閣告示第1号。文化庁 <https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/gendaikana/index.html>）の本文 第1・第2・付記に書いてあることだけです（2026-11-17 に読みました）。
- 答えは本則です。「せかいじゅう／せかいぢゅう」のように、告示が「許容」として両方を認める語は問題にしていません。
